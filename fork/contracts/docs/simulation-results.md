# Deterministic research simulation results

Reproduce with `npm run simulate`. Values below use micro-USDC converted to
USDC. P&L is conditional on activation and excludes the separately logged
network cost allowance. Percentage fees are zero; exact quotes include rounding.
Synthetic calibrations are deliberately assumed, not learned from Gemini.

Every VOID P&L is zero. Each two-trade scenario incurs eight micro-USDC of
rounding reserve (refunded on VOID) and a separate 200-micro-USDC assumed network
cost. The misspecified model loses despite a large modeled edge. Synthetic
historical outcome tables recover conditionals 0.1, 0.5 and 0.9, but comparable
real terminal-outcome data has not been supplied.

Full deterministic output, including individual sizes, limits, realized YES/NO
P&Ls and sensitivity envelopes, is generated by the command above.
